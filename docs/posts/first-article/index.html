欢迎来到我的小站

其实创建这个博客的念头很偶然

一天我闲着没事，在GitHub上弄了个项目，就是这个，然后想着，一个东西分享出来，那不挺好的吗！（虽然GitHub本来就是用来分享的，但考虑到GitHub没那么多人知道）我就觉得搭个博客挺好的，能分享东西，还可以学习一些前端知识,（其实都是用AI的） 一举两得

于是就有了你看到的这个网站

关于我

我是 WIN-VSCODE（网名），一个 2015 年出生的小学生。喜欢折腾 Python，也喜欢鼓捣一些看起来"很酷但没什么用"的小东西。写代码基本靠 AI 帮忙，遇到不会的就问，慢慢也就摸出了一些门道

关于网站

整个网站是用 Hugo 搭的，主题是 Stack，部署在 GitHub Pages 上，完全免费

会写点啥

有一些关于编程的东西会写，生活类的也会写

（然后不知道写啥了）
